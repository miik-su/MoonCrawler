# 实施计划与初始盘点

2026-11-08：指定 GitHub 仓库为空，没有已有代码或测试可迁移。
需求依据：本文的模块能力与验收目标；后续架构变更见正式整改记录。

按独立功能提交，至少 11 次实质提交：

1. 项目结构、依赖、架构与范围。
2. URL 解析、规范化、相对链接与过滤。
3. 公共模型、配置校验与错误分类。
4. Frontier 去重、优先级、租约和状态机。
5. 有界重试、退避与 Retry-After。
6. 全局 / 域名调度、暂停与延迟。
7. Robots 分组、规则匹配、缓存。
8. 安全网络策略与有界 HTTP 适配器。
9. 复用 HTML 生态的页面提取。
10. Pipeline、幂等存储、检查点恢复。
11. 引擎编排、可注入扩展点。
12. CLI、实例、关键集成验证与 CI。

验证仅执行关键部分必要测试和编译检查，不运行全量测试。
优先使用 MoonBit；复用现有 HTTP / HTML 实现，不自研数据库、浏览器或 JS 引擎。
P2（分布式、动态浏览器、PDF、增量抓取）保留为后续扩展。

网络请求与本地存储不具备同一事务，采用至少一次请求与 URL 幂等写入；
检查点仅支持单进程作业，禁止多个进程共享同一作业目录。
