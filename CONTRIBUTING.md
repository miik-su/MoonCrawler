# Contributing

Discuss significant architecture changes in an issue before implementation.
Submit focused changes with a reproduction/regression test and updated public API
interfaces generated by `moon info`. Run formatting, native checking and the narrow
tests affected by the change. See docs/verification.md for commands.

Unless explicitly stated otherwise, contributions submitted for inclusion are
under the project's Apache-2.0 license, consistent with its contribution provision.
No separate CLA is currently required. A DCO-style Signed-off-by is recommended;
do not sign for work you cannot license. Contributors retain their copyrights.

Identify the origin and license of third-party code. Do not submit unauthorized
copies or incompatible material. Dependency changes must include the locked version,
actual license evidence and an update to THIRD_PARTY_NOTICES.md. No curl binary is
redistributed by this repository.

Report security defects through SECURITY.md before public exploit discussion.
